Euler-Lagrange Particle and Field Demo

This document describes euler-lagrange-particle-field-gpu.py, a Python and OpenGL program that compares the Euler-Lagrange equation in ordinary particle mechanics with its field-theory version.

How To Run

From the project directory, run:

python euler-lagrange-particle-field-gpu.py

If you are running inside a virtualenv, you may need to activate it first.

Main Idea

The program is built around one main idea: The Lagrangian is the thing being integrated. The Euler-Lagrange equation is what you get after asking for the action to be stationary.

S = ∫ L ( q , q. ) dt
S = ∫ L ( ψ , ∂μ ψ ) d4x

For a particle, the dynamical variable is a coordinate q(t). For a field, the dynamical variable is a value at every spatial point, such as psi(t, x) in the demo.

Euler-Lagrange Equation Method

The Euler-Lagrange equation is for turning an action into an equation of motion. The motion where tiny changes to that path do not change the action to first order is modeled. In other words,

δS ≠ 0
  1. Choose the object that is allowed to vary: x(t) for a particle or psi(t, x) for a field.
  2. Integrate the Lagrangian or Lagrangian density.
  3. Perturb the object slightly and keep only the first-order change in the action.
  4. Use integration by parts to move derivatives away from the arbitrary perturbation.
  5. Because the perturbation is arbitrary, the factor multiplying it must be zero. That factor is the Euler-Lagrange equation.

The key idea is that the Lagrangian is the input expression. The Euler-Lagrange equation is the derivative condition produced from that expression.

Particle Mechanics Side

The particle side uses a one-dimensional harmonic oscillator:

L = T - V = 12 mv2 - 12 kx2

The Euler-Lagrange equation is:

ddt ( ∂L ∂v ) - ∂L ∂x = 0

Since partial L / partial v = m v, the first term becomes m a. Since partial L / partial x = -k x, the second term is the force from the spring. The result is Newton's law:

ma = F

Particle Panels

  • 3D particle view: shows the mass, spring, force arrow, and m a arrow.
  • Particle integrand plot: shows T, V, and L = T - V.
  • Particle EL terms plot: compares m a and force directly.
  • Residual: shows m a - F, which should remain near zero.

The important point is that L = T - V is the input to the variational problem. The Euler-Lagrange equation differentiates that input into the actual equation of motion.

Field Theory Side

The field side uses a one-dimensional scalar field psi(t, x). This is a simplified visual stand-in for a full spacetime field psi(t, x, y, z).

L = 12 ψt2 - 12 c2 ψx2 - 12 μ2 ψ2

Here L is a Lagrangian density. It is local: every spatial point has its own contribution. Integrating it over space gives an ordinary time-dependent Lagrangian:

L(t) = ∫ L (t,x) dx

Then integrating over time gives the action:

S = ∫ L(t) dt = ∫∫ L (t,x) dx dt

In full 3+1 dimensional field theory, the notation d^4x means:

d4x = dt dx dy dz

Field Euler-Lagrange Equation

The field-theory Euler-Lagrange equation is:

∂μ ( ∂L ∂ ( ∂μ ψ ) ) - ∂L ∂ψ = 0

For the field in the demo, this becomes:

ψtt = c2 ψxx - μ2 ψ

Field Panels

  • 3D field view: shows the current shape of psi(t, x).
  • Density plot: shows the local Lagrangian density and energy density across space.
  • Field EL terms plot: compares psi_tt with c^2 psi_xx - mu^2 psi.
  • Residual: shows the local mismatch in the field equation. It should stay small except for numerical error.

Controls

Preset

Changes particle mass, spring stiffness, field wave speed, and field mass term. The math stays the same, but the relative motion changes.

Play

Advances the particle and field simulations through time.

Reset

Returns the animation to the initial state.

Slider

Scrubs through time so a specific moment can be inspected.

Reading The Dashboard

The left half answers the particle question: "How does L = T - V become F = m a?" The right half answers the field question: "How does a Lagrangian density become a differential equation at every point in space?"

The two red residual curves are the quickest correctness check. They represent the difference between the two sides of the Euler-Lagrange equation. When the residual is near zero, the visualized system is satisfying the equation.
